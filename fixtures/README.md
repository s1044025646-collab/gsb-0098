# 虚构夹具说明

本项目不提供任何真实资料。单一事实来源为 `src/domain/reference.ts` 中的 `FICTIONAL_SEED`：

- 机关：虚构市示例行政机关（`agy_demo`）
- 渠道：线上窗口 / 邮政信函 / 现场窗口（均虚构）
- 申请人：匿名申请人 A/B（假名 + `.invalid` 邮箱）
- 资料：
  - `doc_plan` 河滨步道改造方案：规划摘要、预算明细（公开）+ 内部审批意见（不予公开）
  - `doc_minutes` 联席会议纪要：时间议题（公开）+ 第三方报价（商业秘密，删隐）
  - `doc_public_notice` 施工公告：完全公开

覆盖演示场景：跨假期、范围歧义补正、部分公开、延期（批准后仍逾期/未批准不计入）、重复送达、复议改判。
写入方式：`npm run seed`（库内按固定 ID 幂等），或 `POST /api/admin/seed`。
